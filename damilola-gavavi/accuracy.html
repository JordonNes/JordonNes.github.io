What is being measured?

This fixed cohort uses the first five completed minutes of contract quotes. Collection runs at minute 6 of each 15-minute window and accepts records only before minute 8. It evaluates this specific checkpoint, rather than every changing card suggestion.

The current study compares D&G with the paired YES quote snapshot retrieved when the suggestion is published; its exchange quote timestamp is unverified. The initial study used the completed minute-5 midpoint. Above 50¢ implies UP; below 50¢ implies DOWN; a 50¢ tie has no direction. The comparison excludes ties when comparing the same calls. Each contract is counted once per cohort. No transaction fees, returns or profits are part of this accuracy measure.

Missing records, pending settlements and abstentions remain visible. Earlier pages show earlier windows; the displayed rate covers only the selected twelve windows for the selected market. A small recent sample does not validate the model.
