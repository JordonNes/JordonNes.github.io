# RICHFISH FISH SCALE Cloudflare Worker

Independent from Railway. Reads the public Rich Fish catalogs from GitHub Pages, provides read-only provisional scores with baseline weights K=25%, C=35%, P=40%. Deploy using the GitHub Actions workflow and repository secrets CLOUDFLARE_API_TOKEN and CLOUDFLARE_ACCOUNT_ID. Later connect legitimate first-party journal and community observations; do not treat catalog scores as live catches. The deployment is additive and does not migrate legacy Ask Ray or nearby endpoints.
