THE L&J EVALUATION PIPELINE

Probability, value and economics stay separate
Exact POM→ LEGZ statistical model + evidence→ JINX challenge / support→ LJPC→ POM Value→ Ticket Mode→ Settlement & Calibration

Market price remains evidence and an execution constraint. It becomes a primary ranking objective only in Demon-oriented economics-first selection after the required LJPC gate is met.

FORMULAS

Current public specification

LJPC — final hit probability

LEGZ produces the quantitative baseline probability. JINX contributes a signed contextual adjustment. A tightly gated historical-learning adjustment may be applied only after LSI maturity checks pass.

LJPC = clamp(L + J + Δlearning, 0, 100)
  • L = LEGZ baseline probability.
  • J = JINX signed percentage-point adjustment.
  • Δlearning = gated historical calibration adjustment; currently capped by LSI safety rules.

POM Value — prediction desirability

POM Value should reward both strong evidence and strong hit probability, while penalizing a serious weakness in either dimension. The standard normal-operation score uses their geometric mean.

POM Value = √(LEGZ Value × LJPC)

This keeps a high projected probability with weak evidence from automatically becoming an elite POM, and prevents strong evidence around a low-probability outcome from being mistaken for a safe play.

LEGZ Value — evidence strength

LEGZ Value is not a second hit probability. It measures how much reliable predictive structure is available: sample quality, historical relevance, repeatability, source depth, line/history coverage, matchup features and traceable statistical signals.

The implementation may mature as LSI gains more historical data. New components must be documented and backtested before their weight can influence future predictions.

Demon economics

Demon mode reverses the normal priority only after an LJPC eligibility gate is satisfied. It hunts payout/upside among qualified Normal and Demon POMs; payout never changes LJPC itself.

Demon eligibility → LJPC gate first → then rank qualified POMs by payout / edge opportunity

Market-implied probability, offered price and modeled edge are execution/economics signals, not replacements for prediction confidence.

QC TICKET MODES

Exact offered POMs only

SNS1 / Goblin 1

Probability-first. Uses Goblin POMs and targets the highest LJPC legs. It is intended to be L&J’s most secure construction, subject to current market availability and provenance.

SNS2 / Goblin 2

Probability-first with diversity. Uses Goblin and/or Normal POMs and avoids merely duplicating SNS1 when alternatives clear the gate.

Normal / Market

Uses standard unmarked market POMs. Ranking is prediction-first: LJPC and POM Value dominate; market economics and source depth are tie-breakers.

Aggressive / Demon

Economics-first only after the probability gate. Qualified Normal/Demon POMs compete on payout/upside while retaining an explicit LJPC.

PROVENANCE & SETTLEMENT RULES

No reconstructed certainty
Every published prediction must be traceable. The Prediction Registry retains source snapshot IDs, market class, exact selection/threshold, event identity, model version and evidence references. Started/completed events are not republished as new pregame opportunities. After settlement, only verified recoverable predictions enter accuracy calculations; unresolved records remain UNGRADED rather than being reconstructed from memory.

SCHEMA COMPATIBILITY

Public language vs internal legacy fields

LJPC is the canonical public term. During migration, internal fields lj_probability and lj_confidence remain compatibility aliases for the same final hit-probability value. legz_confidence remains the LEGZ baseline probability input; it is not the same thing as LEGZ Value. jinx_input remains JINX’s signed contextual percentage-point adjustment.

Where an evidence-strength legz_value and combined pom_value are available, they must not be substituted for LJPC. Historical accuracy and calibration remain separate retrospective measures.
